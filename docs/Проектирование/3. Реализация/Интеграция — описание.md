# Интеграция — описание

## Что интегрируем

- `@scrider/editor-react` (DOM/React/`contentEditable`) ↔ `@scrider/editor-core` (State → State).
- `@scrider/editor-core` ↔ `@scrider/delta` (документ и операции).
- Границы обмена: `@scrider/formatter` (Delta ↔ HTML/Markdown и др.) для импорта/экспорта/вставки из разметки.

## Контракт интеграции (кратко)

- UI-слой переводит DOM-события в команды/операции для core и отображает результат.
- Core не зависит от DOM и не хранит DOM-структуры; источник истины — состояние редактора.
- Formatter вызывается только при преобразованиях между Delta и внешними форматами.

## Где проверяем интеграцию

- `demo/` (Vite): ручная проверка базовых пользовательских сценариев.
- Интеграционные тесты React-слоя (DOM) на ключевые сценарии.
