# Реализация — описание этапа

## Цель

Реализовать запланированный функционал редактора и подтвердить работоспособность через `demo/`, тесты и экспортные сценарии.

## Что реализуется

- `@scrider/editor-core`: состояние (`EditorState`), команды, история undo/redo, плагины/реестры.
- `@scrider/editor-react`: UI-обёртка с `contentEditable`, события, toolbar; интеграция с core.
- Интеграция с `@scrider/delta` (модель документа/операций) и `@scrider/formatter` (Delta ↔ HTML/Markdown и др.).

## Выходы этапа

- работающий редактор в `demo/` (Vite) как интеграционный стенд;
- подтверждение базовых сценариев ввода/форматирования/undo/redo;
- подтверждение сценариев импорта/экспорта через formatter (где применимо);
- набор тестов: unit для core + интеграционные тесты для React-слоя.
