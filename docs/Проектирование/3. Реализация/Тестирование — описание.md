# Тестирование — описание

## Принцип

Тестирование подтверждает корректность:

- чистой логики ядра (`@scrider/editor-core`) без браузера;
- интеграции UI-обёртки (`@scrider/editor-react`) с DOM/`contentEditable`;
- преобразований и экспорта через `@scrider/formatter` (где используется).

## Уровни тестов

- Unit-тесты (`Vitest`): команды и инварианты состояния в `editor-core`.
- Интеграционные тесты (DOM): сценарии ввода/выделения/форматирования/undo/redo в `editor-react`.

## Минимальный набор проверок (ориентир)

- ввод текста и базовое редактирование;
- применение inline/block-форматов;
- undo/redo на серии изменений;
- вставка/экспорт в целевые форматы через formatter (если подключено).
