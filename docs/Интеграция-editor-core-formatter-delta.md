# Интеграция: `@scrider/editor-core`, `@scrider/delta`, `@scrider/formatter`

Разделы упорядочены от **домена редактора** к **модели документа** и к **сериализации**. Зависимости: `editor-core` использует `@scrider/delta`; `@scrider/formatter` вызывается при обмене с HTML, Markdown и др. (импорт, экспорт, вставка из разметки).

## `@scrider/editor-core`

- **Что это:** домен редактора: `EditorState`, команды (inline/block, буфер обмена и т.д.), выбор/диапазоны, история undo/redo, реестры модулей/плагинов — чистые данные и функции без DOM.
- **За что отвечает:** что сейчас в документе и что произойдёт после команды; изменения выражаются через **Delta** и операции из `@scrider/delta`.
- **Чего здесь нет:** React, `contentEditable`, прямой работы с DOM (это `@scrider/editor-react` или приложение).

## `@scrider/delta`

- **Что это:** **Delta** — цепочка операций над документом; пакет даёт функции над этими операциями (**OT Delta**: OT = operational transformation — формальные операции над правками, в том числе для undo/redo).
- **Связь с ядром:** в `editor-core` документ хранится как Delta; команды формируют и применяют Delta-операции через этот пакет.
- **Чего здесь нет:** правил HTML/Markdown, UI, прикладной логики редактора как продукта.

## `@scrider/formatter`

- **Что это:** слой сериализации: Delta ↔ HTML, Markdown и др., плюс схема допустимых форматов (маппинг inline/block).
- **Связь с ядром:** не заменяет командный слой `editor-core`. Используется для преобразования Delta во внешний формат и обратно при вводе/выводе разметки.
- **Чего здесь нет:** состояния сессии, истории undo/redo по командам редактора, клавиатурных маппингов.

## Поведение при интеграции

1. Команда → `editor-core` обновляет состояние через `@scrider/delta`.
2. Обмен с внешним представлением → `editor-core` или обёртка передаёт Delta в `@scrider/formatter` и получает результат (или наоборот при импорте).

## Уровни зависимостей

```
@scrider/editor-core
        │
        │ использует
        ▼
@scrider/delta  ◄──────────────────┐
        │                          │
        │ на границах ввода/вывода │
        ▼                          │
@scrider/formatter
```

## Сводка

`editor-core` ведёт состояние и команды поверх Delta; `@scrider/delta` задаёт модель документа и операций; `@scrider/formatter` переводит Delta в обменные форматы и обратно при импорте и экспорте.
